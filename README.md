# BERESin

**Ini web buat apa?**

BERESin dipakai untuk membereskan dua pekerjaan yang sering memakan waktu panitia kegiatan, staf kantor, mahasiswa, dan pelaku UMKM:

1. **Ubah foto struk jadi laporan keuangan LPJ otomatis**: Masukkan banyak foto struk belanja atau nota warung sekaligus, lalu langsung unduh laporan lengkap berisi kalimat pengantar LPJ otomatis, hitungan sisa/kurang dana, tabel rincian, kolom tanda tangan, dan lampiran foto struk ke format **PDF (`.pdf`)**, **Word (`.docx`)**, **Excel (`.xlsx`)**, **CSV (`.csv`)**, **Web (`.html`)**, atau **Teks (`.txt`)**.
2. **Kecilkan ukuran banyak foto sekaligus**: Kompres puluhan foto ke bawah `200 KB`, `500 KB`, atau `1 MB` langsung dari browser HP/laptop, lalu unduh satuan atau dalam satu file `.zip`.

Gratis dipakai sepuasnya tanpa perlu daftar akun.
