# BERESinHAHAY

**Ini web buat apa?**

BERESinHAHAY dipakai untuk membereskan dua pekerjaan yang sering memakan waktu bendahara panitia, staf kantor, dan pelaku UMKM:

1. **Ubah foto nota jadi Excel & PDF LPJ**: Tinggal pilih banyak foto struk belanja atau nota warung sekaligus, cek angkanya sebentar, lalu langsung unduh rekap `.xlsx` dan dokumen `.pdf` A4 lengkap dengan lampiran foto bernomor urut (`#NOTA-001`).
2. **Kompres ukuran foto**: Kecilkan ukuran banyak foto sekaligus (`< 200 KB`, `< 500 KB`, atau `< 1 MB`) langsung dari peramban, lalu unduh satuan atau dalam satu file `.zip` tanpa perlu pindah ke web lain.

Semuanya gratis tanpa batas kuota atau sistem token.
